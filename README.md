## Introduction

This [AH Planner](https://yapdesign.nl/portfolio/ah-planner) is a simple application tool to view your work shifts, ask question or revisions, and even swap upcoming shifts with other colleagues. It's a design concept and proposition to replace the work shift system (GO, still in use 2026) of the Albert Heijn supermarket. 

## Built with a Laravel (PHP) Framework.
- Frontend: Tailwind CSS, Alpine js
- Backend: Livewire with Volt (functional API style), MySQL database

## Feature 1: Calendar & Week overview
View all you work shifts in the calendar. Click on any day to view the week overview as well.
